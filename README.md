# Task 03: Basic DOM Manipulation

An experimental web module focused entirely on dynamically altering the Document Object Model (DOM) directly through frontend user actions.

## Features
* **Dynamic Element Injection:** Dynamically append or delete HTML elements right on the page without performing full browser reloads.
* **State Management:** Toggling CSS classes dynamically based on click triggers (e.g., simple dark/light mode toggles).
* **Event Handlers:** Robust element event binding using classic JavaScript listeners.

## Tech Stack
* HTML5
* CSS3 (Global styling rules)
* Vanilla JavaScript (DOM Selectors, Event Handlers, Class Manipulation)

## How to Run
Open `index.html` inside a web browser and play with the dynamic functional buttons on the interface.
